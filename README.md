# 🍄 Mario Game

A small Mario-inspired game project I built while learning the basics of game development. This was one of my early experiments with implementing platformer mechanics and understanding how the different parts of a game work together.

## 🎮 About the Game

**Mario Game** is an early practice project inspired by classic Mario platformers. The main goal was to learn how to implement basic game mechanics, work with game assets, and experiment with player movement and platforms.

Unlike my newer Mario Clone project, this repository was primarily about learning and practicing implementation rather than building a complete, structured game application.

It was an important starting point for getting more comfortable with game development concepts and figuring things out by writing code and testing it myself.

## 🛠️ What I Was Learning

Through this project, I was exploring concepts such as:

- Implementing player movement and jumping
- Working with game images and visual assets
- Creating platforms and level layouts
- Understanding collision detection and game logic
- Connecting different pieces of code to create interactive gameplay
- Debugging and learning through experimentation

## 🚀 What Came Next

This project helped lay the groundwork for my newer **Mario Clone** project, where I started putting those concepts together into a more complete game application.

In that project, I've been working on features like scrolling levels, custom level layouts, more challenging platforming, and responsive controls for mobile devices.

Looking back, this repository represents an earlier stage of that learning process. It gave me a place to practice the fundamentals before moving on to a larger project.

## 📚 Why I Built This

Most of my development experience has been focused on web development, using technologies like JavaScript, TypeScript, React, and Next.js. I wanted to explore game development and learn how to build something interactive outside the usual website or web application.

Rather than trying to build everything at once, I started by learning how to implement the individual parts of a game. This project was a chance to experiment, make mistakes, debug problems, and get more comfortable with the fundamentals.

It's a small project, but it was part of the process that led me to build something more complete.
